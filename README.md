## Project Title

### AIU Coursera Courses Database System

---

## Project Overview

* A database management system for integrating AIU courses with Coursera programs.
* Helps manage students, instructors, enrollments, licenses, and course progress.
* Provides organized tracking and reporting for academic activities.

---

## Main Objectives

* Manage AIU and Coursera course data efficiently.
* Track student enrollments and course completion.
* Help instructors organize Coursera modules with university courses.
* Generate semester and yearly reports.

---

## Key Features

### Student Management

* Register students in courses
* Track student progress and completion

### Instructor Management

* Assign instructors to courses
* Allow instructors to manage course mappings

### Course Management

* Store AIU and Coursera course information
* Manage modules, enrollments, and deadlines

### Reporting System

* Generate reports for enrollments and progress
* Monitor licenses and student participation

---

## Database Design

### Entities Used

* Students
* Instructors
* Courses
* Programs
* Modules
* Licenses
* Enrollments
* Fields
* Admins

### Relationships

* Students enroll in courses
* Instructors teach courses
* Programs manage students and instructors

---

## Database Techniques

### ERD (Entity Relationship Diagram)

* Used to design relationships between entities.

### Normalization

* Applied 1NF, 2NF, and 3NF
* Reduced redundancy and improved database efficiency.

---

## Technologies Used

* SQL
* Database Modeling
* Relational Algebra
* ERD Design

---

## Business Queries

* Highest enrolled courses
* Average modules per course
* Instructor teaching statistics
* Student distribution across fields

---

## Project Outcome

* Efficient and organized database system
* Improved course and enrollment management
* Better tracking and reporting for AIU and Coursera integration
